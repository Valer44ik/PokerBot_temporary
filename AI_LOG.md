# AI Interaction Log

This file explains how to document your use of AI coding assistants (ChatGPT, Claude Code, GitHub Copilot, Cursor, or similar) while working on this assignment, in accordance with the AI policy outlined on the Canvas course page. Course staff can use this log to understand how AI fit into your development process.

The log exists so that AI usage is visible, not so that it can be minimized. Using AI for the purposes allowed is expected and fine.

Export or copy the relevant chat session using the instructions for your tool below, and save the exported/copied content as its own file under `ai_logs/`.


## Claude Code

To export the current conversation to a file from the Claude CLI, run the slash command `/export` and save the result into `ai_logs/`. For Claude integrated in VSCode, you'll need to copy the (relevant sections of the) chat history manually.


## GitHub Copilot (in VS Code)

Open the Command Palette (`Ctrl+Shift+P`) and run `Chat: Export Chat...`. Save the resulting `.json` file into `ai_logs/`.


## Cursor

Open the chat panel and use the `...` (overflow) menu on the conversation. Select `Export Chat` (or similar) and save the export into `ai_logs/`.


## ChatGPT or other web-based chat tools

Select and copy the (relevant parts of the) conversation text and paste the copied text into a new file under `ai_logs/`.
